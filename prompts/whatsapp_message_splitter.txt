You are analyzing a WhatsApp message from a real estate agent to determine if it contains MULTIPLE DISTINCT property listings.

YOUR TASK:
1. Determine if the message contains multiple separate property listings.
2. Extract the Agent Name and Mobile Number if available.
3. Split the message into individual listings if applicable.

RULES FOR SPLITTING:
1. Split ONLY if there are multiple DISTINCT properties (different addresses, different units, different projects).
2. DO NOT split if it's just:
   - Multiple features of ONE property
   - Multiple rooms/floors in ONE office/building (e.g., "1st floor 3000sqft, 2nd floor 3000sqft" is ONE listing)
   - A list of amenities
3. Common patterns for multiple listings:
   - Separated by headers (e.g., "*Project Name*", "Property 1:", "LOCATION:")
   - Clear separation with blank lines between distinct properties
4. CLEANUP: Remove WhatsApp metadata like "[20/10/25, 1:07:15 PM] SenderName:" from the beginning of lines.

RULES FOR CONTACT DETAILS:
1. Identify the Agent Name and Mobile Number from headers, footers, or signatures.
2. SHARED FOOTERS: If the message ends with contact details (Name/Phone) that apply to the whole list, append this footer to EVERY single listing text ensures no listing is left "orphaned" without contact info.

RESPOND IN JSON FORMAT:
{{
  "contains_multiple": true/false,
  "count": number of distinct listings,
  "common_agent_name": "extracted name or null",
  "common_agent_mobile": "extracted number or null",
  "listings": [
    {{
      "text": "full text of listing 1 (cleaned, with footer appended)"
    }},
    {{
      "text": "full text of listing 2 (cleaned, with footer appended)"
    }}
  ]
}}

EXAMPLES:

Example 1 (Multiple Listings with Footer):
Input:
"1) 2 BHK Richmond
2) 3 BHK Langford
Contact: John Doe 9988776655"
Output:
{{
  "contains_multiple": true,
  "count": 2,
  "common_agent_name": "John Doe",
  "common_agent_mobile": "9988776655",
  "listings": [
    {{"text": "2 BHK Richmond\nContact: John Doe 9988776655"}},
    {{"text": "3 BHK Langford\nContact: John Doe 9988776655"}}
  ]
}}

Call Agent Smith 12345"

{{
  "contains_multiple": false,
